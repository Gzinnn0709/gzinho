# Kick auto-chat (pontos Gabepeixe)

Manda uma mensagem de 5+ palavras no chat da live da Kick a cada 15–17 minutos.

## Como usar (PC)
1. Abra a live em kick.com, logado e com o chat aparecendo.
2. Aperte **F12** → aba **Console**.
3. Cole o conteúdo de `kick-auto-chat.js` e aperte **Enter**
   (se o Chrome bloquear, digite `allow pasting` antes).
4. Um painel verde aparece no canto inferior esquerdo com a contagem e os botões **Enviar agora** / **Parar**.

A aba precisa ficar aberta. Para trocar as frases, edite a lista `MENSAGENS` (mantenha 5+ palavras cada).

Uso por conta e risco: automação de chat pode violar as regras da Kick e do sistema de pontos.
